# Hybrid Reading

Лёгкий Android-клиент для чтения веб-сайтов: один WebView, меню сайтов, блокировка рекламы
по каждому сайту отдельно, домашняя страница и сохранение места чтения.
Сайтов по умолчанию нет — вы добавляете свои (например, `*****.net`, `*****.me`, `*****.com`).

## Возможности

- **Кнопка меню.** Круглая кнопка поверх страницы: её можно перетащить в удобное место, а по
  нажатию раскрываются «Главная», «Сайты» и «Удалить блок». Положение запоминается.
- **Домашняя страница** — стартовый экран: подсказка про входы, кнопка «Добавить сайт», список
  сайтов с их состоянием блокировки рекламы. Приложение помнит, где вы остановились — на главной
  или на сайте, — и открывает это же после перезапуска.
- **Сайты.** Добавление по ссылке (`*****.me` — схему можно не писать), сразу после добавления
  сайт открывается. Долгое нажатие — правка названия, ссылки и блокировки рекламы; удаление
  с подтверждением и выбором, стирать ли данные сайта. Активный сайт, страница и позиция прокрутки
  сохраняются.
- **Скрытие блоков на сайте.** В меню есть «Удалить блок»: касаетесь ненужного блока на странице —
  он подсвечивается, исчезает и больше не появляется на этом сайте. Скрытые блоки считаются
  в правке сайта, там же кнопка «Вернуть». Приложение ничего не блокирует по спискам: если блок
  мешает, его убирает пользователь.
- **Полноценный браузер.** Все `http/https` открываются внутри (OAuth Telegram/VK/SSO не выкидывает
  из приложения), `window.open` — отдельным окном, `alert/confirm/prompt`, выбор файла, камера и
  микрофон с системными разрешениями, полноэкранное видео, внешние схемы (`tg:`, `mailto:`).
- **Чтение.** Плавная прокрутка без бокового отскока; страница и позиция прокрутки запоминаются,
  чтение продолжается с того же места даже после выгрузки процесса.
- **Энергопотребление.** При погашенном экране WebView останавливается (`onPause` + `pauseTimers`),
  в фоне таймеры страницы гасятся через 10 секунд. Замерено: 0 % CPU в фоне.
- **Данные сайтов.** В правке сайта видно, сколько места он занимает («Занято 1,8 МБ»), и есть два
  действия: «Кэш глав» (только Cache API — скачанные главы и картинки, вход сохраняется) и
  «Полная очистка» (ещё localStorage, IndexedDB, service worker, куки и общий кэш страниц — сайт
  забывает вход). При удалении сайта данные стираются, если оставить галочку «Удалить кэш и данные».
  Все эти действия спрашивают подтверждение.

## Про входы на сайтах

У каждого сайта своя сессия: вход на одном сайте не открывает доступ к другому, и приложение
ничего не объединяет. Входите на самом сайте — его форма входа, пароль или кнопка «Войти через
VK/Telegram» работают прямо в приложении.

Google не разрешает вход во встроенных браузерах (`403 disallowed_useragent`), а куки системного
браузера приложению недоступны. Поэтому сайты с входом только через Google открываются во внешнем
браузере: там вход работает, но сессия останется в браузере и в приложение не переносится.

## Сборка

Нужны JDK 17–21 (**JDK 25 не подходит**: AGP 8.9.2 падает) и Android SDK с platform 35.

```bash
./gradlew assembleRelease        # или gradlew.bat на Windows
./gradlew testDebugUnitTest lintDebug
```

`scripts/verify.sh` (bash) собирает тесты, lint и оба APK разом; `JAVA_HOME` можно задать переменной.

**Кириллица в пути к проекту.** На Windows каталог с русскими буквами ломает тестовый раннер Gradle
(`ClassNotFoundException` для тестовых классов): classpath передаётся во временном файле, который JVM
не разбирает для не-ASCII путей. Лечится ASCII-джойнкцией:

```bat
mklink /J C:\hybrid_build "C:\путь\с кириллицей\HybridReading"
```

и сборкой из `C:\hybrid_build`.

## Структура

| Файл | Роль |
|---|---|
| `MainActivity.kt` | Activity, навигация (сайт/главная/меню), реакция на погашенный экран |
| `HomeScreen.kt` | Домашняя страница: подсказка про входы, добавление сайта, список сайтов |
| `WebScreen.kt` | WebView, клиенты, попапы, диалоги, файлы, права, косметика |
| `SitesStore.kt` / `UrlTools.kt` | Сайты в SharedPreferences, разбор и нормализация ссылок |
| `SitesDrawer.kt` | Меню «Сайты», карточка «Главная», диалоги добавления/правки/удаления |
| `SiteCache.kt` | Размер данных сайта, очистка кэша глав и полная очистка |
| `HiddenBlocks.kt` | Скрытые пользователем блоки: селекторы и CSS по каждому сайту |
| `MenuController.kt` | Перетаскиваемая кнопка меню с тремя действиями |
| `ReadingState.kt` | Последняя страница, прокрутка, были ли на главной |
| `App.kt` | Инициализация, фильтр запросов service worker |

Тесты: `app/src/test/java/<package>/` — 34 JVM-теста (UrlTools, SitesStore, формат размера).

## Как считается и чистится кэш

Размер и очистка привязаны к origin, поэтому приложение на секунду открывает нужный сайт в скрытом
WebView и работает с его хранилищем: `navigator.storage.estimate()` для размера, `caches` +
`localStorage` + `indexedDB` + `navigator.serviceWorker` для очистки, куки гасит `CookieManager`.
Соседние сайты не затрагиваются; общий HTTP-кэш страниц очищается только при полной очистке.

## Приватность

- Нет аналитики, рекламных SDK и собственных сетевых запросов: всё грузит сам сайт.
- Куки и сессии хранятся только на устройстве, `android:allowBackup="false"` — в облачный бэкап
  они не попадают.
- Отладка WebView включается только в debug-сборке.

## Известные ограничения

- Вход через Google внутрь приложения перенести нельзя (см. выше).
- Блоки скрываются точечно: после обновления страницы с другой разметкой селектор может перестать
  совпадать — тогда блок нужно скрыть заново.
- Размер кэша не учитывает куки — их размер браузерный движок не отдаёт.
- Release-сборка в `app/build.gradle.kts` подписана debug-ключом, чтобы APK ставился поверх
  предыдущих версий. Для публикации в магазине замените на собственный keystore.
