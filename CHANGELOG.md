# Что изменилось с 1.0.0

Версия 1.0.0 была клиентом одного сайта с собственной библиотекой скачивания: 18 файлов,
2902 строки, APK 16 МБ (собирался только debug), release не собирался. Всё, что не входило
в белый список домена, уходило во внешний браузер, поэтому любой OAuth-вход обрывался.

Ниже — что изменилось по сути, без разбивки по промежуточным версиям.

## 1. Приложение стало многопользовательским по сайтам, а не клиентом одного сайта

- Список сайтов в меню: добавление по ссылке (`*****.me` — схему можно не писать), правка
  названия и адреса, удаление с подтверждением, отметка активного сайта.
- Встроенного сайта нет: приложение стартует с домашней страницы, пока пользователь не добавил
  свой первый сайт. Добавленный сайт сразу открывается.
- Ненужные блоки на странице можно скрыть касанием — по каждому сайту свой набор; в правке сайта
  видно, сколько скрыто, и есть кнопка «Вернуть».
- Активный сайт, страница и позиция прокрутки сохраняются между запусками; приложение помнит
  и то, был ли пользователь на главной странице или на сайте.

## 2. Авторизации и всплывающие окна начали работать

- Все `http/https`-переходы остаются внутри приложения: OAuth Telegram/VK/SSO, платёжные страницы
  и редиректы больше не выбрасывают пользователя в браузер.
- `window.open` открывается отдельным окном с собственным заголовком, результат возвращается
  в основную страницу; окно закрывается и уничтожается корректно.
- Работают `alert/confirm/prompt`, выбор файла из системы, камера и микрофон с запросом
  разрешений (в том числе для QR-входа), полноэкранное видео, внешние схемы `tg:`/`mailto:`.
- Google-вход внутрь WebView перенести нельзя — платформа отвечает
  `403 disallowed_useragent`; это ограничение отмечено в README.

## 3. Вместо блокировки рекламы — скрытие блоков вручную

- Списков рекламных сетей, перехвата запросов и косметической фильтрации больше нет: приложение
  ничего не блокирует и не вмешивается в загрузку страницы.
- Вместо этого «Удалить блок» в меню включает режим выбора: сверху панель с «Отменой», касание
  элемента обводит его рамкой и спрашивает подтверждение. «Отмена» снимает выделение и оставляет
  режим включённым; «Скрыть» убирает блок и тоже оставляет режим — выходят только кнопкой «Отмена».
- Селектор блока короткий: якорные атрибуты (`data-testid`, `aria-label`, `id`) либо путь
  `тег:nth-of-type`, без десятков CSS-классов.
- Селекторы хранятся по сайту; в правке сайта видно их количество и есть «Вернуть».

## 4. Библиотека скачивания заменена офлайн-режимом самого сайта

- Удалены `Downloader`, `DownloadService`, `ChapterParser`, `SiteClient`, `ReaderScreen`,
  `ShelfScreen`, `ChaptersScreen`, `BookScreen`, `Library`, `ReadMarks`, `DragSelect` — 11 файлов
  и около 1500 строк, вместе с зависимостями OkHttp, Coil и `material-icons-extended`.
- Скачанные главы теперь хранит сам сайт (Cache API + service worker), приложение только
  не мешает: `navigator.storage.persist()` просит систему не вытеснять кэш.

## 5. Данные сайтов: размер, очистка, удаление

- В правке сайта видно, сколько места он занимает («Занято 1,8 МБ»).
- «Кэш глав» — удаляет только Cache API: скачанные главы и картинки, вход сохраняется.
- «Полная очистка» — плюс localStorage, IndexedDB, service worker, куки и общий кэш страниц:
  сайт забывает вход.
- Удаление сайта стирает его данные (галочка в диалоге, включена по умолчанию); без неё данные
  остаются на диске.
- Всё это привязано к origin: чистка одного сайта не задевает соседние. Каждое действие
  спрашивает подтверждение с описанием последствий.

## 6. Чтение, плавность и энергопотребление

- Плавная прокрутка: `setOffscreenPreRaster`, отсутствие overscroll-подсветки, CSS
  `scroll-behavior: smooth`.
- Позиция чтения переживает выгрузку процесса: холодный старт возвращает ту же страницу и скролл.
- При погашенном экране WebView останавливается, в фоне таймеры гасятся через 10 секунд.
  Замерено: 0 % CPU в фоне, процесс в состоянии `cached`.

## 7. Название, иконка, производительность

- Продукт называется «Hybrid Reading» (было имя сайта) — свой адаптивный знак и монохромный
  слой для Android 13+.
- APK: 16 МБ → 1,2 МБ release (8,8 МБ debug).
- Холодный старт: 444–625 мс в 1.0 → 375–412 мс.
- Прокрутка страницы: 6 jank-кадров из 389 (1,54 %), 90-й перцентиль 10 мс.

## 8. Надёжность и безопасность

- Краш рендерера WebView больше не убивает приложение: страница пересоздаётся с сообщением.
- Устранены утечки Activity при открытии/закрытии попапов.
- Внешние ссылки из `intent` проходят нормализацию — `javascript:` и прочие схемы отбрасываются.
- `allowBackup="false"` (куки и сессии не уходят в облачный бэкап), `usesCleartextTraffic="false"`,
  отладка WebView включается только в debug-сборке.

## 9. Меню и чтение

- Кнопка меню стала перетаскиваемой: её положение запоминается. По нажатию раскрываются три
  действия — «Главная» (дом), «Сайты» (глобус), «Удалить блок» (перечёркнутый глаз); сама кнопка —
  три точки, чтобы не путалась с кнопками сайта.
- Убран боковой отскок при вертикальном пролистывании: `overScrollMode = NEVER`, изображения и
  таблицы ограничены шириной экрана. Горизонтальная прокрутка страницы при этом не отключается —
  иначе ломается вертикальный скролл.

## 10. Профиль, обновления и история чтения

- Экспорт/импорт профиля: сайты, лимиты кэша и скрытые блоки в JSON через системный файловый диалог.
- «Продолжить чтение» на главной: последние страницы с названиями, переход возвращает на место.
- «Проверить обновления»: сравнение с последним релизом на GitHub, загрузка APK и установка поверх.
- У каждого сайта задаётся порог кэша (100/200/500 МБ или выключено) — при превышении скачанные
  главы чистятся автоматически; в правке сайта есть кнопка «Обновить страницу».

## 11. История, закладки, отображение и бэкап

- Кнопка меню: градиент с окантовкой, реакция на нажатие (масштаб) и перетаскивание,
  прилипание к ближнему краю, автоскрытие за край с видимой полоской и возврат по касанию.
- Кнопка меньше на 35 % (36 dp вместо 56), спрятанную кнопку проще достать: у края работает
  невидимая зона касания 44 dp на всю высоту кнопки. Поднесли к краю — прячется сама.
- Положение кнопки задаётся отступами от краёв, поэтому она не уезжает при повороте экрана.

- «История» — отдельный пункт меню рядом с «Главной» и «Сайтами»; на главной появился блок
  «Библиотека» с кнопками «История» и «Закладки (N)», из профиля они убраны.
- У кнопок меню появились подписи на полупрозрачных подложках; кнопка закладки уменьшена вдвое.
- В закладках: счётчик в заголовке, удаление корзиной и открытие касанием по строке.

- Экран истории: поиск по названию и адресу, закладки (звезда в меню и в списке), очистка истории.
- Масштаб текста (90–150 %) и принудительная тёмная тема — для каждого сайта отдельно.
- Список скрытых блоков: «Показать» на пять секунд и «Убрать» по одному элементу.
- Недельный автобэкап профиля в «Загрузки/HybridReading» (WorkManager, только при нормальном заряде).
- Все правки страницы (плавность, постоянное хранилище, скрытые блоки, автоочистка кэша) уходят
  одним JS-вызовом вместо четырёх; размер кэша кэшируется на 10 минут с кнопкой «Пересчитать».
- WebView больше не открывает локальные файлы: `allowFileAccess` и `allowContentAccess` выключены.

## 12. Инженерная часть

- 56 тестов, включая Robolectric на хранилища, профиль, кнопку меню, историю и закладки.
- ktlint в сборке (`ktlintCheck`), правила в `.editorconfig`; lint без ошибок.
- `WebScreen` разбит на Compose-слой и `WebEngine`; сборка и тесты идут в GitHub Actions.
- `scripts/verify.sh` — тесты, lint и оба APK одной командой; Gradle wrapper 8.13 в репозитории.
- Кириллица в пути проекта на Windows ломает тестовый раннер Gradle — обход через ASCII-джойнкцию
  описан в README.
- Кода стало меньше: 18 файлов / 2902 строки → 11 файлов приложения и 5 файлов тестов, 3242 строки
  вместе с тестами.
